# 联播广告保量的分配与补播

分钟用同一转播日 UTC 零点为基准；区间左闭右开。曝光单元是频道、地区、广告素材、连续播出片段的组合。`base` 是已播；`plan` 是可选补播，不作为实际曝光。可选片段的人数是经片段保障核定后的区间。`intersection` 表示列出的所有曝光单元在同一地区的人数交集，不是仅出现于这些单元的人数；未给约束的交集未知。锁档只是档位占用，不是交付已证实。本地商务回执的 `slot_cancelled` 才释放档位；`evidence_withdrawn` 只撤销引用的曝光证据。`exclusive` 非空且相同表示两单不能独占同一次曝光；订单在区间内要求一段不少于 `seconds` 的完整广告。

## 数据包

`sample/` 是本地合成的业务记录，均为 UTF-8 CSV；`table-format.json` 给出各表的列顺序与标量类型，`str` 中 `-` 表示不适用，逗号分隔多值。不同表中同名业务标识用于关联，具体含义见上文。资料入口只检查表头和格式，不对业务状态作判断。

## 运行

使用 Python 3.11 标准库，不需要安装三方依赖。读取样例与运行资料检查：

```sh
python3 intake.py
python3 -m unittest discover -s tests -v
```

也可以将同格式的资料目录作为 `intake.py` 的位置参数。
